# Aethertek Plugin Manager

Update supported Dalamud plugins from trusted ZIP download links, with package checks and backups.

## Get started

1. Add `https://aethertek.io/x.json` to Dalamud's custom plugin repositories and install **Aethertek Plugin Manager**.
2. Open `/apm` and copy the publisher's direct ZIP link.
3. Check **I trust the publisher**, then click **Check clipboard for updates**.

APM can install missing public hosts for MOM, DhogNav, Deep Ducking, XA Zod and Eureka Suite before applying their private updates. Keep APM enabled until it finishes.
